# Windows-Server-2022-Active-Directory-Domain-Services-AD-DS-Home-Lab

This project simulates a real-world enterprise Active Directory environment using Windows Server 2022 and a Windows 11 client VM. It focuses on implementing centralized domain management, security policies, and resource access control through AD DS, DNS, GPOs, and FSRM. Plans of adding SCCM endpoint management, Azure Arc Active Directory/Cloud integration, and AI implementations.
